# Прогін евалів через підписку Claude Code замість API-ключа

## Context and Problem Statement

Повний прогін датасету коштує ~130 викликів моделі. API-ключа під рукою не було, а
підписка Claude Code вже оплачена. Питання: чи можна прогнати евали через неї, не
переписуючи агента.

`claude -p` (headless-режим) — документований програмний вхід у підписку. Але він віддає
**текст**, а агентський цикл LangChain побудований на нативному tool calling.

## Considered Options

* **Чекати API-ключ** — нічого не міняє в коді, але блокує вимірювання на невизначений час.
* **Переписати агента під Claude Agent SDK** — тоді агентський цикл стає чужим, разом із
  middleware (PII, стеля кроків, guard на деструктив), а міряти треба саме наш цикл.
* **Замінити тільки транспорт: LangChain-модель поверх `claude -p`** — цикл, middleware,
  критик і структурований вивід лишаються ті самі; tool calling доводиться емулювати
  промптовим JSON-протоколом.

## Decision Outcome

Chosen option: «Замінити тільки транспорт». Резолвер обирає провайдера за тим, що
доступно: OpenRouter → `ANTHROPIC_API_KEY` → `claude -p`. Агенти про це не знають.

**Ціна названа явно і зафіксована в коді:** tool calling тут промптовий, а не нативний.
Це інший механізм з іншою поведінкою на межах — інакше ламається на довгих аргументах,
інакше обирає між кількома інструментами, інакше тримається схеми. Тому транспорт
потрапляє в `meta` звіту, а дельта між прогонами на різних транспортах не рахується —
так само, як не рахується між різними суддями.

### Consequences

* Good, because повний прогін датасету перестав залежати від наявності ключа.
* Good, because під вимірюванням лишився саме наш агент з нашими guardrails.
* Bad, because числа з цього транспорту не порівнюються з прогоном через API;
  `tool_recall` — найімовірніший кандидат на заниження.
* Bad, because промптовий протокол ламається способами, яких у нативного немає: п'ять
  окремих режимів збою знайдено живими прогонами і закрито (усі з тестами).
* Bad, because один виклик — один процес, ~5–7 с накладних; для датасету прийнятно,
  для проду ні. У проді лишається звичайний API-клієнт.
